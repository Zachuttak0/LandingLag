# LandingLag
Ever had your game lag badly on the "Entering Atmosphere" screen, causing someone's voice to get stuck repeating the same sound over and over during the lag? LandingLag aims to fix this annoying issue.

This is an issue caused by inefficient unity code in a core function that runs many times during setup. LandingLag modifies this code to help reduce the lag, keeping your game as smooth as butter while you wait to land.

What it does
- Helps reduce lag during the "Entering Atmosphere" screen.
- Prevents the annoying issue of player voices getting stuck due to lag by preventing the lag.
- Is especially useful for modded lobbies with increased player counts or lots of mods.

Results may vary depending on your PC and mod setup.
